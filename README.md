## 📖 Project Description
Student Marks Analysis is a Python-based project that analyzes student marks and calculates important statistics such as Total Marks, Average Marks, Highest Marks, and Lowest Marks.

## 🎯 Objectives
- Learn Python fundamentals
- Understand list operations
- Perform basic data analysis
- Use Python built-in functions effectively

## 🛠️ Technologies Used
- Python
- Visual Studio Code
- GitHub

## 🚀 Methodology
1. Store student marks in a Python list.
2. Calculate total marks using `sum()`.
3. Calculate average marks using total marks divided by the number of students.
4. Find the highest marks using `max()`.
5. Find the lowest marks using `min()`.

## 💻 Python Code

marks = [85, 90, 78, 92, 88]

total = sum(marks)
average = total / len(marks)
highest = max(marks)
lowest = min(marks)

print("Student Marks:", marks)
print("Total Marks:", total)
print("Average Marks:", average)
print("Highest Marks:", highest)
print("Lowest Marks:", lowest)
